## Reporting Issues

If you encounter a bug, crash, or usability issue:

1. Go to the **[Issues tab](https://github.com/gatling/gatling-studio/issues)**
2. Click **“New issue”**
3. Choose an appropriate issue template:
    - 🐛 **Bug Report**
    - 💡 **Feature Request**
4. Include:
    - Your operating system and version
    - Gatling Studio version
    - Steps to reproduce the problem
    - Logs or screenshots (if applicable)

Your feedback helps us make Gatling Studio better for everyone ❤️
